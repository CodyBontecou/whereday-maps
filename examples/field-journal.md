# Synthetic Field Journal

Copy `synthetic-atlas.json` into your vault alongside this note, then enable Whereday Maps. All records are invented.

```whereday
source: synthetic-atlas.json
journal: true
show_receipt: true
auto_refresh: true
date: 2026-05-04
tile_provider: none
journal_folder: Whereday Demo/Daily
places_folder: Whereday Demo/Places
trip_folder: Whereday Demo/Trips
```
