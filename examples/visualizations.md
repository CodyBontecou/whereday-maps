# Whereday figures

Copy `synthetic-atlas.json` into your vault's `exports` folder, then try each
figure independently. All data in this example is invented.

```whereday
source: exports/synthetic-atlas.json
view: stay-strip
date: 2026-05-04
```

```whereday
source: exports/synthetic-atlas.json
view: day-dial
date: 2026-05-04
```
